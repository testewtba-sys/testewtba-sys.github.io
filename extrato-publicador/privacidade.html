Política de Privacidade do Extrato Publicador

Última atualização: 25 de outubro de 2026

O que é

O Extrato Publicador é uma ferramenta de uso interno do canal Extrato da História. Ela é usada apenas pelos responsáveis pelo canal, no próprio computador, para gerenciar os vídeos do canal.

Quais dados acessa

Com a autorização do dono da conta, a ferramenta usa os Serviços de API do YouTube para:

  • ler e alterar os dados dos vídeos do próprio canal (título, descrição, tags, categoria, idioma, miniatura, playlists e configurações de público);
  • ler as estatísticas e relatórios do próprio canal (YouTube Analytics e YouTube Reporting).

A ferramenta não acessa dados de outros canais nem de espectadores individuais.

Como os dados são guardados e usados

  • A autorização (token) fica salva apenas no computador de quem usa a ferramenta.
  • As estatísticas são usadas só para acompanhar o desempenho dos vídeos do próprio canal.
  • Nenhum dado é vendido, compartilhado ou enviado a terceiros.

Serviços de API do YouTube

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, você concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Também é possível apagar o arquivo de autorização (token) do computador.
